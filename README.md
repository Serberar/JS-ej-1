# Ejercicios de JavaScript · 1. Fundamentos

Primera colección de ejercicios de JavaScript: variables, operadores, arrays, condicionales y bucles. Cada ejercicio tiene su enunciado (`.md`) y mi solución (`.js`) al lado.

## Contenido

| Carpeta | Tema |
|---|---|
| `1.variables` | Declarar y reasignar variables. |
| `2.operators` | Operadores aritméticos (incluido el resto `%`) y de asignación. |
| `3.arrays` | Crear, leer y modificar arrays. |
| `4.conditionals` | `if` / `else`. |
| `5.loops` | Bucles `for`. |
| `extra` | Retos que mezclan todo: filtrar usuarios por edad, clasificar películas por duración, sumar y promediar ventas... |

## Cómo ejecutarlos

```bash
node 3.arrays/exercise-1.js
```
